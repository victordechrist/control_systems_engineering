## 2. PID Algorithm & Tuning Rules

The continuous-time parallel PID controller transfer function is given by:

> **PID Controller Formula:**
> C(s) = Kp + Ki / s + Kd * s = Kp * (1 + 1 / (Ti * s) + Td * s)

### Ziegler-Nichols Ultimate Sensitivity Tuning Table

When increasing Kp with Ki = 0 and Kd = 0 until the closed-loop system reaches marginal stability (sustained oscillations):

| Controller Type | Proportional Gain Kp | Integral Time Ti | Derivative Time Td |
| :--- | :--- | :--- | :--- |
| **P** | 0.50 * Ku | — | — |
| **PI** | 0.45 * Ku | 0.83 * Pu | — |
| **PID** | 0.60 * Ku | 0.50 * Pu | 0.125 * Pu |

### Exercise 1 (Warm-up): Individual P, I, D Component Effects

Analyze how each component affects transient metrics on a 2nd-order DC Servo plant:

> **Plant Transfer Function:**
> P(s) = 10 / (s^2 + 3*s + 2)

```python
import numpy as np
import matplotlib.pyplot as plt
import scipy.signal as signal

# Plant G(s) = 10 / (s^2 + 3s + 2)
num_p = [10.0]
den_p = [1.0, 3.0, 2.0]

# Time array
t = np.linspace(0, 10, 1000)

# Evaluate Proportional-only control with varying gains
gains = [1.0, 3.0, 8.0]
plt.figure(figsize=(9, 5))

for Kp in gains:
    # Closed-loop transfer function: T(s) = Kp*P(s) / (1 + Kp*P(s))
    den_cl = [1.0, 3.0, 2.0 + 10.0 * Kp]
    num_cl = [10.0 * Kp]
    sys_cl = signal.TransferFunction(num_cl, den_cl)
    t_out, y_out = signal.step(sys_cl, T=t)
    plt.plot(t_out, y_out, label=f"Kp = {Kp}")

plt.axhline(1.0, color="black", linestyle="--", label="Reference Setpoint")
plt.title("Effect of Proportional Gain Kp on Step Response")
plt.xlabel("Time (s)")
plt.ylabel("Position y(t)")
plt.grid(True, alpha=0.3)
plt.legend()
plt.tight_layout()
plt.show()
```

### Exercise 2 (Core): Ziegler-Nichols Closed-Loop Tuning

```python
import numpy as np

# Ziegler-Nichols tuning formula implementation
def calculate_zn_pid(Ku, Pu):
    """
    Computes PID gains using Ziegler-Nichols ultimate gain method.
    Ku: Ultimate gain where system oscillates continuously.
    Pu: Ultimate period of sustained oscillation (seconds).
    """
    Kp = 0.60 * Ku
    Ti = 0.50 * Pu
    Td = 0.125 * Pu

    Ki = Kp / Ti
    Kd = Kp * Td

    return Kp, Ki, Kd

# Example: Ku = 12.5, Pu = 1.4s
Ku_example = 12.5
Pu_example = 1.4

Kp, Ki, Kd = calculate_zn_pid(Ku_example, Pu_example)
print(f"Tuned PID Gains -> Kp: {Kp:.3f}, Ki: {Ki:.3f}, Kd: {Kd:.3f}")
```

### Exercise 3 (Boss Level): Discrete PID Controller with Anti-Windup Clamping

```python
import numpy as np
import matplotlib.pyplot as plt

class DiscretePID:
    def __init__(self, Kp, Ki, Kd, dt, u_min=-10.0, u_max=10.0, N_filter=10.0):
        self.Kp = Kp
        self.Ki = Ki
        self.Kd = Kd
        self.dt = dt
        self.u_min = u_min
        self.u_max = u_max
        self.N_filter = N_filter # Derivative filter coefficient

        self.integrator = 0.0
        self.prev_error = 0.0
        self.prev_derivative = 0.0

    def update(self, setpoint, measurement):
        error = setpoint - measurement

        # Proportional term
        P_term = self.Kp * error

        # Derivative term with low-pass filtering
        de = (error - self.prev_error) / self.dt
        D_term = (self.Kd * de * self.N_filter + self.prev_derivative) / (1 + self.N_filter * self.dt)
        self.prev_derivative = D_term
        self.prev_error = error

        # Tentative control output before saturation check
        u_unsat = P_term + self.integrator + D_term

        # Saturation clamping
        u = np.clip(u_unsat, self.u_min, self.u_max)

        # Anti-windup: only integrate if output is not saturated
        if u_unsat == u:
            self.integrator += self.Ki * error * self.dt

        return u

print("Discrete PID controller class initialized with anti-windup and derivative filtering.")
```
